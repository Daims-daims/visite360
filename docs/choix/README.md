# Choix à rediscuter

Un fichier par étape. Chacun garde le détail d'un choix fait avant ou pendant l'étape : options étudiées, raisons, coûts relevés, sources, et ce qui pourrait faire changer d'avis. Le propriétaire a validé ces choix pour avancer et prévoit d'y revenir « en temps voulu ».

Le journal `docs/decisions.md` garde la décision elle-même, en bref, avec un renvoi ici. Pour revenir sur un choix, on ajoute une décision qui le remplace, comme pour toute décision.
